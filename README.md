# signatur-bilder

Logos und Icons für die E-Mail-Signaturen von kandidat.io und freshtalents. GitHub Pages veröffentlicht dieses Repo unter `https://signatur.kandidat.io/`.

| Datei | Verwendung |
|---|---|
| `logo-kandidat-io.png` | Logo kandidat.io |
| `logo-freshtalents.png` | Logo freshtalents |
| `icon-mail.png` | Icon vor der E-Mail-Adresse |
| `icon-telefon.png` | Icon vor der Telefonnummer |
| `icon-web.png` | Icon vor der Website |
| `quellen/` | Originaldateien in voller Größe |

## Regeln

- Dateien nie umbenennen oder löschen. Jede verschickte Mail lädt ihre Bilder beim Öffnen neu von diesen URLs.
- Ein neues Logo ersetzt die Datei unter demselben Namen. Dann zeigen auch alte Mails das neue Logo.
- Logos quadratisch, 156 × 156 px (doppelte Anzeigegröße), PNG. Icons 64 × 64 px, PNG.

Die Signaturen selbst erzeugt der Claude-Skill **email-signatur**. Dessen Quelle liegt in einem eigenen, privaten Repo.
